# Свой игровой бот для Telegram (как старый @gamee)

Игры отправляются в любой чат через `@имя_бота`, у каждой карточки своя таблица
Top Players, при новом рекорде Telegram сам пишет в чат «X scored N in …».

## 1. Бот в @BotFather

1. `/newbot` — создай бота, сохрани токен.
2. `/setinline` — выбери бота, задай подсказку (например `game…`). Без этого `@имя_бота` в чате не сработает.
3. Игры создаются в BotFather: **Games** → **Create a New Game** (или команда `/newgame`).
   Создавай в этом порядке, short name вводи точно:

   | short name | Title        | Что за игра                       |
   |------------|--------------|-----------------------------------|
   | `racer`    | Grid Racer   | гонка, обгоняй машины             |
   | `ski`      | Snow Zigzag  | снежок катится между заборами     |
   | `tiles`    | Tile Dash    | куб бежит по плиткам, три полосы  |
   | `knives`   | Blade Wheel  | кидай ножи во вращающийся круг    |

   Если какая-то игра ещё не создана, бот покажет только те, что идут в списке до неё.

В проекте лежат ещё две игры — `cannon` (Star Cannon) и `runner` (Roof Runner).
Чтобы включить: зарегистрируй их и раскомментируй строки в `GAMES` в `src/worker.js`.

## 2. Деплой на Cloudflare

```
npx wrangler deploy
npx wrangler secret put BOT_TOKEN        # токен из BotFather
npx wrangler secret put WEBHOOK_SECRET   # любая строка из A-Z a-z 0-9 _ -
```

## 3. Подключить вебхук (один раз)

Открой в браузере:

```
https://<адрес-воркера>/setup?key=<WEBHOOK_SECRET>
```

Должно вернуться `{"ok":true,...}`.

## 4. Играть

В любом чате набери `@имя_бота ` — появится список игр. Выбери, нажми **Play**.

## Как добавить ещё игру

1. Положи её в `public/<short_name>/index.html`, подключи `<script src="/common.js"></script>`.
2. Когда раунд закончился, вызови `gameOver(score, restart)` — очки уйдут в чат, покажется таблица.
3. Добавь строку в `GAMES` в `src/worker.js`.
4. Зарегистрируй в BotFather через `/newgame` с тем же short name и задеплой заново.

## Ограничение

Очки считает браузер игрока, поэтому технически их можно подделать (у @gamee было так же).
Подделать можно только свой результат, не чужой.
